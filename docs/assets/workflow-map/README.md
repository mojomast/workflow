# Workflow poster

A single-page map of the build workflow documented in this repository.

| File | What |
|---|---|
| [workflow-map.png](workflow-map.png) | Raster poster, used as the README banner |
| [workflow-map.html](workflow-map.html) | Print-resolution HTML version (3200×2480). Open the file locally; it loads fonts from the `fonts/` folder beside it |

The poster is a picture of the workflow already described in chapters 01–12. It does not add private hosts, tokens or URLs.

## Fonts

The HTML poster embeds these SIL Open Font License 1.1 families as `.woff2` files:

- [IBM Plex Sans](https://github.com/IBM/plex) and [IBM Plex Mono](https://github.com/IBM/plex), © IBM Corp.
- [Instrument Serif](https://github.com/googlefonts/instrument-serif), © Rodrigo Fuenzalida
