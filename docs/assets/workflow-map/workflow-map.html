The rizzstack workflow, contract to deploy

How a feature becomes merged, deployed code: a frozen contract, a validated brief, an event-driven factory that dispatches bees to hyvv hosts, verifier-owned evidence, and a pull request that merges only when it is green and independently reviewed.

Who does what

workflow is the method and its contracts. bundlebees is the Hermes coordinator plugin. hyvv runs the bees on each worker host. Orbit is the operator's desktop and Observatory. Workers are called bees.
